🧠 Janet MCM Core v0.1.0 — Initial Public Commons Release

An initial public Modest Cognition Model (MCM) release — open, deterministic, and free forever.

This release marks the public publication of Janet, a Modest Cognition Model (MCM) — a proposed class of artificial cognition built for safety work, transparency, determinism, and stability, not scale.

MCM = Modest Cognition Model — a proposed cognitive class defining deterministic, modular, bounded artificial cognition.

Within the Symbound ecosystem and its derivatives, MCM refers to the Modest Cognition Model class; this project does not claim authority over unrelated external uses of the acronym.

MCMs are not LLMs, not neural networks, and not agent frameworks.
Janet represents a transparent, auditable, modular artificial cognition engine that grows only through human-gated curriculum.

This release establishes a conceptual, legal, and architectural foundation for the MCM class in the global commons.

Terminology boundary: MCM cognition language names a proposed architecture and
taxonomy for deterministic artificial systems. It is not a claim of sentience,
consciousness, personhood, subjective experience, or guaranteed correctness.
